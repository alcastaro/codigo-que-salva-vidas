Entendiendo Google Crisis Resilience · DevFest Santo Domingo 2026

Elige una pista. A y B siguen al huracán Melissa (Jamaica, octubre de 2025), desde el pronóstico hasta la alerta; C vigila la erosión en República Dominicana con AlphaEarth. No necesitas saber programar ni crear un proyecto en la nube: solo una cuenta de Google.

Antes de empezar (3 minutos)

  1. Saca tu API key gratuita de Gemini en aistudio.google.com/apikey: pulsa Create API key y cópiala. El extra D no la necesita.
  2. Abre tu pista con el botón Abrir en Colab y guarda tu copia: File → Save a copy in Drive (Archivo → Guardar una copia en Drive).
  3. En Colab, abre la llave 🔑 (Secretos) de la barra izquierda, pulsa Add new secret, escribe el nombre GOOGLE_API_KEY, pega tu key y activa Notebook access.
  4. Ejecuta las celdas en orden con ▶️ o Shift + Enter. Si Colab avisa que el notebook no es de Google, pulsa Run anyway (Ejecutar de todos modos).
  5. Nunca pegues la key dentro de una celda: trátala como una contraseña.

Cada cuaderno trae todo su código, comentado, y explica cómo leer los resultados y cómo adaptarlo a otro huracán u otra región. Los datos se descargan solos desde GitHub; no tienes que bajar nada a mano. Instrucciones completas y soluciones a errores comunes en el README del repositorio.
